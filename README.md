## About

QuietIoT is an IoT-powered noise monitoring system for work environments. It is designed to give users quick and clear insights into noise levels across different areas, such as offices, homes or study spaces. By doing so, QuietIoT aims to help reduce noise-related distractions and improve productivity.

This repository contains the code for the website frontend created for the QuietIoT project. The website allows users to log in, view connected devices, monitor live readings and analyse noise trends through dashboard visualisations.
